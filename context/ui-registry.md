# UI Component Registry (Living Document)

## Registered DSL Elements & Components
* `Document`: Root HTML5 document with title, meta tags, head builder, and body builder.
* `HeaderView`: Reusable navigation/header bar component.
* `Main`, `Article`, `Section`, `Nav`, `Footer`: Semantic layout elements.
* `H1` .. `H6`, `P`, `Text`, `Span`, `A`: Typography and text primitives.
* `VStack`, `HStack`, `ZStack`, `Spacer`: Flexbox layout containers.
* `Form`, `Input`, `TextArea`, `Button`, `Select`, `Option`: Form controls and inputs.
* `Spinner`: Animated loading indicator for async server states.
* `MarkdownView`: Server-side and client-side Markdown rendering element.
* `ForEach`: Declarative collection iteration result builder construct.
* `IslandContainer` (`<kite-island>`): Client WASM hydration boundary container.
